AI PROMPT LOG — Notes Board Project
File: ai_prompt_log.txt
Date: 2026-10-24

PURPOSE
This log records five important prompts used during the Notes Board project, the
main response or outcome, and why each prompt was used. Responses are summarized
rather than reproduced as full transcripts. Prompts are kept in their original
wording where available.

============================================================
ENTRY 1 — Frontend landing page

Prompt:
“I need hero page to only showcase the website with a scroll animation with all
the features. I want the scroll animation to zoom into a notebook with bold
text. Don’t use AI-slop colours. Generate me code.”

Response / outcome:
Generated Vue frontend code for a product showcase with a notebook-focused
visual, scroll-driven zoom, feature sections, responsive styling, and
reduced-motion support.

Why used:
To create a distinctive landing page that presents the Notes Board product
and its features through a scrolling visual story.

============================================================
ENTRY 2 — Plan the backend

Prompt:
“Ok done with the front end now backend.”

Response / outcome:
The next development phase was planned around a backend with persistent note
storage, authentication, and create/read/update/delete (CRUD) functionality.

Why used:
To move from the frontend showcase toward a functional MVP.

============================================================
ENTRY 3 — Choose and build the backend

Prompt:
“Build the Notes Board backend step by step for my existing Vue + Vite
frontend. Scope: full backend with CRUD notes. Database: Supabase PostgreSQL.
User authentication: include signup and login. I am a beginner using VS Code
on Windows. Give exact terminal commands and complete file contents, one step
at a time, preserving my existing frontend.”

Response / outcome:
The proposed approach used Supabase Auth and PostgreSQL with the existing Vue
frontend, including database setup, Row Level Security (RLS), the Supabase
client, and environment variables.

Why used:
To define a practical MVP backend while keeping the setup manageable for a
beginner and preserving the existing frontend.

============================================================

“for 4th command it is showing error”

The setup guidance focused on installing Node.js LTS, restarting VS Code,
checking `node -v` and `npm -v`, and identifying the exact terminal error

Why used:
To establish the local development environment and resolve setup problems
before continuing with implementation.
